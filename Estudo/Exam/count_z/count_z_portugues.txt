Nome do exercício : count_z Arquivo esperado : count_z.c Funções
permitidas : write ——————————————————————————–

Escreva um programa que receba uma string como argumento e exiba a
quantidade de letras ‘z’ contidas nessa string, seguida por uma quebra
de linha.

O programa deve receber exatamente 1 argumento.

Se o número de argumentos for diferente de 1, o programa deve exibir
apenas uma quebra de linha.

Se a string não contiver nenhuma letra ‘z’, o programa deve exibir
apenas uma quebra de linha.
